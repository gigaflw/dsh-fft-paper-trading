# 模拟交易

股票与商品期货模拟盘。在 DSH 侧栏打开「模拟交易」，输入代码就能预览成本、下单、持仓、复盘；账本是本地文件，重启后自动恢复。

## 功能

- **股票**：交易、批量（按 CSV 权重一次买入）、行情、持仓、订单、复盘。
- **期货**：交易、持仓、订单、复盘。按手交易、保证金占用、T+0 平仓。
- **对话里也能操作**：查行情、预览下单、撤单、看持仓与复盘（`paper_*` 与 `futures_*`，共 18 个工具）。
- 股票与期货各自独立账户、独立账本，互不影响。首次打开自动开户：股票 10 万元、期货 100 万元模拟资金，可随时注资、提款或重置（重置前自动备份账本）。

## 安装

```sh
dsh plugin add @dsh-ft/dsh-fft-paper-trading
```

- 安装后自带 FTShare 行情、交易日历与 K 线视图，不需要再单独安装其他插件。
- 需要 DSH `>= 0.2.0-rc.2`。
- 完整 K 线视图依赖本机 Python 3.10+，首次启动会联网准备运行环境；准备失败不影响下单、持仓和复盘。
- **不要**与 `@dsh-ft/dsh-fft-bundle` 或其他自带 FTShare 数据服务的入口包同时安装：数据服务行会重复，插件管理器里相关项将无法单独开关。

## 行情与 API Key

行情来自 FTShare，分两档：

- **已配置 API Key**：实时行情。
- **未配置 API Key**：免费档，报价取最近一个收盘价（盘中等于上一交易日收盘），分钟线与实时接口不可用；匿名额度约 500 次/天，用尽后行情暂停，可用手填参考价继续交易，额度恢复后自动恢复。

API Key 在 DSH 设置中配置，申请地址：<https://ftai.chat/ftshare>。

面板顶栏会显示数据源状态（已配置 / 免费 / 无 / 无效）；行情不可用时会说明原因并给出「获取 API Key」或「重试」入口。交易日历降级为「周一至周五」时面板会标注（此时节假日会被当作交易日，T+1、挂单过期与结算按工作日估算）。

## 使用要点

- 交易页填完代码、方向、数量即自动预览费用与成交后现金；市价单按最新价一次成交，限价单未穿越时挂单等待。
- 涨停/跌停、停牌、T+1 可卖、佣金/印花税/过户费按 A 股规则模拟；行情缺失时可用参考价下单。
- 期货只在日盘时段接受委托，15:30 按收盘价结算并做风险检查；夜盘、股指/国债期货、交割与移仓不在本期。

## 数据与隐私

- 账本保存在本机 DSH 数据目录（默认 `~/.dsh`）下的 `paper-trading/`（股票与期货各一份），不上传任何服务器。
- 重置账户会先备份到同目录的 `backups/`；账户异常锁定时面板会给出账本路径，可导出后排查。
- 仅用于模拟与研究，不接实盘，不构成投资建议。

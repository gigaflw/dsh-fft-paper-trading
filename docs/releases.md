# Release Notes

## v0.2.0

### 功能更新

- 新增「一揽子」页签：按 CSV 权重一次配股，预览股数、费用与剩余现金后批量下单
- 同一批次重试不会重复下单

### 组件更新

- `@ft/dsh-fft-paper-trading`：`v0.1.0` → `v0.2.0`

## v0.1.0

### 功能更新

- 模拟盘拆成独立仓库，可单独安装
- 模拟交易、持仓、订单、复盘四个页签与 8 个 `paper_*` 工具
- 行情与交易日历走宿主 `ftshareData`，缺失时降级为手填参考价 + 工作日日历

### 组件更新

- `@ft/dsh-fft-paper-trading`：新增 `v0.1.0`

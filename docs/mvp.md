# 模拟盘 v0.1：交付范围与验收

> 状态：已交付（分支 `feat/paper-trading`，包版本 `0.1.0`）。架构、账本规则与扩展点见 [design.md](design.md)；
> 本文只写「做了什么」和「怎么验」，不重复设计。
> 目标包：`@dsh-ft/dsh-fft-paper-trading`

## 1 目标与判定

一句话：让用户在 DSH 左侧栏里完成「预览 → 下单 → 撤单 → 看持仓 → 复盘」，模型也能通过工具做同样的事，两边共用一份账本。

v0.1 完成的三条判定：

1. 左侧栏「模拟盘」能打开，交易、持仓、订单、复盘四个页签可用。
2. 八个 `paper_*` 工具可调用，写入同一账本。
3. 重启 DSH 后，现金、持仓、订单与重启前一致。

## 3 入口与页面

| 入口 | 谁用 | 怎么进 |
| --- | --- | --- |
| 左侧栏「模拟盘」 | 人 | 点左侧栏图标，面板占据主区域 |
| Agent 工具 | 模型 | 对话中调用 `paper_*` |

面板是全局视图，不绑定会话；切走即卸载、面板轮询停止（宿主撮合不受影响）。账户头有总资产、可用现金、累计盈亏、今日盈亏、刷新、资金（注资/提款）、重置（二次确认）；盈亏已剔除净入金。

页面元素：

| 页签 | 元素 |
| --- | --- |
| 交易 | 代码、买卖/市价限价分段、数量、限价或参考价、自动预览卡、成交/挂单回报、买入/卖出 |
| 持仓 | 表格：代码、名称、数量、可卖、成本、现价、浮盈亏；行内「卖出」 |
| 订单 | 挂单表（可撤单）+ 历史表 |
| 复盘 | 区间按钮、统计带、权益曲线、成交记录 |

**输入即反馈**：交易页任一字段变化 300ms 后自动 `order/preview`，行情行与费用一起刷新；没有「查行情」「预览」按钮。
**刷新**：挂载即拉取账户、订单、成交、复盘；可见时每 5 秒 `tick` 并静默重载；表头刷新同时重算预览；提交、撤单、重置立即重载。

## 4 工具（8 个）

| 工具 | 用途 |
| --- | --- |
| `paper_account` | 查账户；`reset=true` 且 `confirm=true` 时重置 |
| `paper_quote` | 查报价 |
| `paper_preview` | 预览金额、费用、现金影响、可卖、最大可买 |
| `paper_order` | 市价/限价下单，支持 `requestId` 幂等 |
| `paper_cancel` | 撤挂单 |
| `paper_status` | 持仓 + 挂单 + 最近成交 |
| `paper_tick` | 刷新行情、撮合挂单、处理过期 |
| `paper_review` | 复盘：权益曲线、回撤、统计、已实现盈亏 |

每个工具用 `output.render` 产出中文摘要；没有工具卡时也能读。工具只调 `PaperService`，不读写文件。

## 5 RPC 子集

面板与卡片走同一个路由 `POST /api/ft-paper-trading`：

`health`、`account/get`、`account/init`、`account/reset`、`settings/get`、`market/quote`、`market/bars`、`order/preview`、`order/place`、`order/cancel`、`tick`、`list/orders`、`list/trades`、`review/get`。

`settings/update` 尚未实现（v0.2）。

## 6 关键交互

### 6.1 下单

```
输入代码 → 填方向/数量/类型/限价/参考价
  → 输入变化 300ms 后 order/preview（行情、金额、费用、现金影响、可卖）
  → 用户确认 → order/place（requestId）
  → 市价：filled；限价已穿越：filled；限价未穿越 / 非连续时段：pending / queued
  → 表单显示成交/挂单/拒绝回报；持仓/订单/复盘刷新
```

### 6.2 撤单

挂单行「撤单」→ `order/cancel` → 状态变 `canceled`；已成交返回 `ORDER_NOT_PENDING`。

### 6.3 失败

| 场景 | 表现 |
| --- | --- |
| 行情不可用 | 预览内联红字；下单按参考价成交或返回 `QUOTE_UNAVAILABLE`（无 TTL） |
| 现金不足 | 预览提示，提交被拒（`INSUFFICIENT_CASH`） |
| T+1 锁定 | 可卖为 0；行内卖出禁用，提交返回 `T1_LOCKED` |
| 账户 blocked | 顶部红条，下单/撤单禁用 |
| 重复提交 | 幂等返回同一订单，不重复成交 |
| 重置未确认 | `INVALID_ARGUMENT` |

## 7 验收清单

按顺序跑一遍，全部通过才算 v0.1 达标：

1. 安装插件，左侧栏出现「模拟盘」图标；点开即自动开户 10 万元。
2. 账户头显示总资产与可用现金；四个页签都在。
3. 输入 `600519.SH`（或裸 `600519`，会解析为 `600519.SH`）；买入 100 股市价，预览自动显示金额与佣金/印花税/过户费，价格等于行情最新价。
4. 提交后订单变 `filled`，持仓出现，可卖为 0，现金减少。
5. 当日卖出被拒（`T1_LOCKED`）。
6. 把系统日期改到下一交易日（或测试时钟）后 `tick`，可卖解锁，卖出成交。
7. 挂一个低于现价的限价买单，状态 `pending`；`tick` 未触价仍 pending；撤单成功；不撤则收盘过期。
8. 重启 DSH，账户、持仓、订单与重启前一致。
9. 复盘页出现权益曲线与统计；重置后账户清空，`backups/` 下多一份事件备份。
10. 不启动 FTShare 服务（或接口失败）时，面板仍能打开、账户与历史可读；行情、预览、tick 显示失败提示而不是崩溃。
11. 对话里让模型「查账户 / 预览买 100 股 / 下单 / 复盘」，结果与面板一致。
